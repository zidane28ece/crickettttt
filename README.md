# 🏏 IPL Auction Website

🎮 A simple and interactive **IPL Auction Game** built using HTML, CSS, and JavaScript.

## ✨ Features

🏆 Select your IPL team
💰 Manage team purse
🏏 Bid for players
👤 Buy players
📋 View your squad
❌ Mark players as unsold
🔄 Reset the auction

## 🛠️ Technologies

🌐 HTML
🎨 CSS
⚡ JavaScript

📁 IPL-Auction

## ▶️ How to Run

1. 💻 Open the project in **VS Code**
2. 📄 Open `index.html`
3. 🖱️ Right-click → **Open with Live Server**
4. 🌐 Play the IPL Auction!
